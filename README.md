> [!NOTE]
> ### Project Evolution and current Status
>
> - **V1 (This Repo):** My first attempt: built with Vanilla JS, [Firebase](https://firebase.google.com), and [Socket.IO](https://socket.io). Abandoned due to state sync and scaling limits.
> - **V2:** I later rebuilt it from scratch with [Vue](https://vuejs.org) and just Socket.IO to create a cleaner, component-driven frontend architecture.
> - **V3 (Active Development):** Then I rebuilt it again using **Vue**, **[Colyseus](https://colyseus.io)** and **[TypeScript](https://www.typescriptlang.org)** for a scalable, server-authoritative multiplayer backend. I copied most GUI and logic from the previous attempt though.
>
> Unfortunately the active V3 codebase is closed-source for anti-cheat security and proprietary protection.

# 🏞️ City Country River (V1, outdated)

City Country River is an open source online party game similar to [Categories](https://en.wikipedia.org/wiki/Categories_(game)). The name comes from 'Stadt Land Fluss' which is the german version of the game.

## Release

The game is still in early development and I don't know anything about servers and backend so it will still take a lot of time. I'm trying my best to get it done quickly.

Update 06/03/25: Setting up the server and database was very easy, but making the lobby system is really hard.
